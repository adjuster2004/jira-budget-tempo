# Jira Budget Monitor - статистика затрат по задачам

Запускается в docker без прав sudo

Доступ к странице по http://0.0.0.0:8501/


## 🛠️ Последовательность
- **Склонировать репозиторий**
```bash
git clone https://github.com/adjuster2004/jira-budget-tempo/
cd jira-budget-tempo
```

- **Собираем образ**
```bash
docker build -t jira-monitor .
```

- **Запускаем контейнер**
```bash
docker run -d \
  --name jira-app \
  --restart unless-stopped \
  -p 8501:8501 \
  -v $(pwd)/config.json:/app/config.json \
  jira-monitor
```

- **Открываем в браузере**
http://0.0.0.0:8501/

- **Заполняем поля**
Jira Domain
Токен / Cookie

Токен можно создать в Профиль - Персональные токены

- **При изменении значения Ключ проекта**
Обязательно нажать Сохранить настройки

Работает сортировка, фильтрация и выгрузка в csv.
Можно выбрать светлую или темную темы.

## 🛠️ Функциональность
- **Работа с Jira и Confluence**

  В левом меню указываются подключения к Jira и Confluence
  После построения таблиц можно выгружать в Confluence

- **Кеширование данных**

  Даже если произошел разрыв связи, доступ к построению отчетов остается до обновления стараницы
  
- **Задачи**

  В этой закладке можно строить отчеты по проектам, отрасли, командам и сотрудникам для подсчета времени по Видам работ.
  Используется каскадная фильтрация Команда - Сотрудник с учетом срока, указанного в "Период отображения ворклогов"
  
- **Эпики**

  В этой закладке можно строить отчеты по проектам, отрасли, эпикам, командам и сотрудникам для подсчета времени по эпикам.
  Используется каскадная фильтрация Команда - Сотрудник с учетом срока, указанного в "Период отображения ворклогов"

- **Детализация**
  В этой закладке можно строить отчеты по проектам, отрасли, командам и сотрудникам для подсчета времени по списанию времени.
  Используется каскадная фильтрация Команда - Сотрудник с учетом срока, указанного в "Период отображения ворклогов"

- **QC Темпо**

  В этой закладке можно строить подробные отчеты по списанию Темпо сотрудниками за указанный в "Период отображения ворклогов" период.
  Используется каскадная фильтрация Команда - Сотрудник с учетом срока.
  Имеется подсветка Темпо записей, если комментарий к записи слишком короткий, либо не указан аккаунт.
  По результатам отчета можно сгенерировать отчет в txt в формате:
    "Название компании - (Продукт) - Тема задачи - комментарии". Полноценный отчет за указанный период по проделанной работе.

- **Табель**

  В этой закладке можно проверить табель из 1С. Присутствуют выборка по командам и подсветка тех, у кого его отличия в табеле.

- **Левое меню**

  Можно найти пользователя по username / Фамилии / JIRAUSER{number}
